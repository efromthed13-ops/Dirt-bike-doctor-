# Troubleshooting Guide

## Bike Will Not Start

### Check 1: Fuel
- Verify fresh fuel
- Check fuel flow
- Inspect carburetor

### Check 2: Spark
- Remove spark plug
- Test spark
- Inspect ignition connections

### Check 3: Compression
- Check kick starter resistance
- Perform compression test
- Inspect valves if needed

### Check 4: Timing
- Inspect timing marks
- Check timing chain condition
